# SKYPRO Ön Muhasebe

Cari takip, tahsilat-ödeme, çek-senet, kasa-banka, vade takvimi ve raporlar.

- Program bu adresten yüklenir ve kendiliğinden güncellenir.
- **Veriler bu sunucuya gönderilmez.** Her firmanın verisi kendi bilgisayarındaki klasörde, parolayla şifrelenmiş (AES-256) dosyalarda durur.
- Kurulum: sayfayı Microsoft Edge ile açın → adres çubuğundaki "Uygulamayı yükle" simgesi → Yükle.
